# 가치관 소개팅

조건은 **양쪽 모두** 맞게, 가치관은 **깊게** 맞춰 주는 소개팅 매칭 앱 프로토타입입니다.
추천 상대와 그 상대를 고른 로직(단계별 인원, 점수 계산식)을 화면에서 그대로 보여줍니다.

**배포 주소: https://babo-gd.github.io/sogaeting-app/** (휴대폰으로 열면 앱처럼 보여요)

## 실행

Node.js만 있으면 됩니다. 설치할 패키지는 없습니다.

```bash
npm start      # http://localhost:5173
npm test       # 매칭 로직 · LLM 매칭 API 테스트 (가짜 Ollama 사용)
```

## AI 매칭 (로컬 LLM이 직접 매칭)

**AI 매칭** 탭에서는 점수 계산 없이 **LLM이 직접** 매칭 상대를 고르고, 매칭이 성사되면 두 사람이 왜 매칭됐는지 설명합니다.
자기소개 로컬 LLM 프로젝트(Ollama + `exaone3.5:2.4b`)를 이 앱의 매칭 엔진으로 합친 것입니다.

1. **후보 거르기** — 서로의 "반드시" 조건(나이·거리·흡연·절대 안 됨 가치관)을 통과한 이성만 후보로 둡니다. 후보 순서는 추천 점수와 상관없이 섞습니다.
2. **특징 리스트업** — 나와 후보들의 특징(자기소개·관심사·핵심 가치관 답·꼭 바라는 것·나와 같은 답)을 글로 정리합니다. 화면의 "📋 LLM에게 보내는 특징 목록"에서 그대로 볼 수 있습니다.
3. **LLM이 매칭** — LLM이 특징을 읽고 가장 잘 맞는 3명을 순서대로 골라 이유를 씁니다. 답은 후보 기호(A, B, C…)만 고를 수 있는 JSON 형식으로 제한합니다. 후보가 8명을 넘으면 8명씩 예선을 치르고 각 조 2명이 결선에 올라갑니다.
4. **매칭 성사 후 설명** — 신청이 승인되면(AI 매칭 탭, 신청함, 추천 카드) **💞 왜 매칭됐을까?** 버튼으로 LLM이 두 사람의 특징을 읽고 매칭된 이유 · 잘 맞는 점 · 맞춰 갈 점 · 첫 만남 추천을 설명합니다(답이 생성되는 대로 화면에 표시).

- 가입 단계와 내 프로필에 **자기소개**(150자) 칸이 있고, LLM이 이 글도 읽습니다.
- 브라우저 → `server.js`(`POST /api/ai-match`, `POST /api/match-explain`) → Ollama 순서로 연결됩니다.
- Ollama가 꺼져 있거나 배포 사이트(GitHub Pages)처럼 서버가 없으면, 규칙(추천 점수)으로 대신 고르고 같은 형식의 설명을 보여 주며 화면에 그렇게 표시합니다.
- 그래픽카드 없이 CPU로 돌아가서 매칭은 1~3분, 설명은 1~2분 정도 걸립니다(4코어 노트북 기준). LLM이 작아서 가끔 특징을 섞어 말할 수 있습니다.

### 실행 (Windows)

1. [Ollama](https://ollama.com)와 [Node.js](https://nodejs.org) LTS를 설치합니다.
2. `setup.bat` 더블클릭 — 처음 한 번만, 모델(`exaone3.5:2.4b`, 약 1.6GB)을 받습니다.
3. `start.bat` 더블클릭 — Ollama 실행 → 서버 실행 → 브라우저에서 http://localhost:5173 이 열립니다.

직접 실행하려면 `ollama pull exaone3.5:2.4b` 후 `npm start`. 다른 모델은 `OLLAMA_MODEL=모델이름 npm start`, Ollama 주소가 다르면 `OLLAMA_URL`을 지정합니다.

## 추천 로직

1. **양방향 반드시 조건** — 내 조건(나이·거리·흡연·외모·"절대 안 됨" 가치관)을 상대가 만족하고, 상대 조건도 내가 만족해야 후보가 됩니다.
2. **가치관 궁합 (60%)** — 질문마다 내 답 · 바라는 답 · 중요도(0/1/10/50)를 받아
   `내 만족도 = Σ(중요도 × 일치) ÷ Σ중요도`, `궁합 = √(내 만족도 × 상대 만족도)`로 계산합니다.
3. **관심사 성향 (25%)** — 관심사 30개를 8가지 성향 벡터로 임베딩하고 `(코사인 유사도 + 1) ÷ 2`로 계산합니다.
4. **선호 조건 (15%)** — "되면 좋음" 조건을 얼마나 만족하는지 양쪽 평균을 냅니다.
5. **종합 점수** = 가치관 × 0.6 + 관심사 × 0.25 + 선호 조건 × 0.15, 높은 순으로 추천합니다.

추가로 3번 이상 또는 15초 이상 본 프로필은 "관심 있게 본 상대"로 다시 추천하고,
추천이 0명이면 이유와 조건 완화 방법(적용 시 늘어나는 인원)을 안내합니다.

## 기능

- 동물 캐릭터 · 프로필 사진(최대 3장, 넘겨 보기) · 단계별 가입
- 전국 17개 시·도, 230개 시·군·구 지역 선택과 거리 계산
- 매칭 신청 / 대기 / 승인 / 거절, 승인 시 72시간 카카오 ID 공개
- 서로 추천된 사이에서 먼저 말을 걸면 생기는 채팅
- 1위 추천 이유, 카드별 점수 계산식, 가상 회원 전체의 추천·제외 사유

## 참고

- 서버가 없는 프로토타입이라 모든 데이터(프로필, 사진, 신청, 채팅)는 브라우저(localStorage)에만 저장됩니다.
- 가상 회원 200명과 그들의 응답(신청 응답, 채팅 답장)은 테스트용 샘플 데이터입니다. 카카오 ID는 `demo-` 접두어를 붙인 가짜 값입니다.

## 구조

| 파일 | 역할 |
|---|---|
| `js/matching.js` | 양방향 조건 필터, 가치관 궁합, 관심사 임베딩, 종합 점수 |
| `js/aimatch.js` · `js/llm.js` | LLM 매칭: 특징 리스트업, 프롬프트, 답 검증, LLM이 없을 때 대체 결과 |
| `server.js` | 정적 파일 + 로컬 LLM API (`/api/ai-match`, `/api/match-explain`) |
| `js/explain.js` | 단계별 인원, 점수 계산식, 1위 이유, 0명일 때 완화 제안 |
| `js/data.js` · `js/regions.js` | 질문·선택지·관심사 벡터, 전국 지역 좌표 |
| `js/profiles.js` | 가상 회원 생성(시드 고정) |
| `js/requests.js` · `js/chat.js` · `js/views.js` · `js/photos.js` | 매칭 신청, 채팅, 머무는 시간, 사진 |
| `js/app.js` · `css/style.css` | 화면 |
